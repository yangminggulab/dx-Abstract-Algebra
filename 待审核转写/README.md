本目录里的内容是早期 OCR 批量转写结果，现已确认**不能直接并入正文**。

## 当前结论

- 这里的文件只保留两种用途：
  - 作为知识点覆盖清单，查看哪些标题需要重做；
  - 少量纯 Markdown 文字节可作为辅助参考。
- 这里的文件**不再作为正文来源**。
- 后续正式整理请以 [待审核转写_重做](</Users/liubike/Desktop/python for notion/半成品-近世代数/待审核转写_重做>) 为准。

## 已确认的问题

- 中文数学图片经 OCR 后大量乱码，不能信任。
- 文中混入大量 Notion URL 编码链接，属于噪音。
- 存在很多空占位或只有元数据的节。
- `[来源上级主题]`、`[来源路径]`、`[关联图片]` 这类块不应进入正文。

## 建议使用方式

- 查看 `\section*{...}` 标题时，把它们当作 checklist。
- 若某节只有纯文本 Markdown，没有 OCR 乱码，可人工清洗后再判断是否复用。
- 若某节依赖图片内容，应回到原始图片重新转写，不再使用本目录里的 OCR 文本。
